Plane · Guía de datos

Datos de Plane en Power BI

Cada tabla tiene su propia dirección web. La conectas una vez en Power BI (o en Excel) y, a partir de ahí, solo pulsas Actualizar para tener los datos al día. No hace falta programar ni descargar ficheros.

1. Lo que necesitas

Dirección de Plane

La que usas para entrar en Plane, por ejemplo https://plane.tudominio.com

Nombre del espacio

Lo que va después del dominio en la barra del navegador: en …/acme/projects es acme

Un token (la llave de acceso)

Es un texto que empieza por plane_api_. Te lo da el administrador de Plane, o lo creas tú en Plane: tu foto (abajo a la izquierda) → Settings → Personal access tokens → Add access token, con caducidad o Never expires. Solo se muestra una vez: guárdalo.

El token ve lo mismo que su dueño. Para tener las horas de todo el equipo, el token debe ser de un administrador del espacio; con el de un miembro, solo salen sus propias horas.

Trátalo como una contraseña. Quien lo tenga puede leer los datos. No lo pegues en correos ni lo compartas; si se pierde, se borra en la misma pantalla de Plane y se crea otro. Los informes con horas por persona son datos personales: compártelos solo con quien deba verlos.

2. Conectar una tabla en Power BI

  1. En Power BI Desktop: Inicio → Obtener datos → Web.
  2. Marca Avanzado.
  3. En Elementos de la URL, pega la dirección de la tabla (sección 4), con tu dominio y tu espacio.
  4. En Parámetros de encabezado de solicitud HTTP, escribe X-API-Key en la casilla de la izquierda y pega tu token en la de la derecha.
  5. Aceptar. Si pregunta cómo acceder, elige Anónimo → Conectar (la llave ya va en el token).
  6. Verás la tabla con sus columnas: Cargar. Repite con cada tabla que quieras.

3. Cómo se relacionan las tablas

Las ocho tablas forman un modelo en estrella: las tablas de datos (azules) guardan lo que se mide y las tablas de búsqueda (grises) sirven para filtrar y agrupar. Se unen por las columnas que empiezan por ID.

Después de cargar las tablas, abre la vista Modelo (el tercer icono de la izquierda). Power BI suele crear solo estas relaciones porque las columnas se llaman igual; comprueba que están todas y que no sobra ninguna. Si falta alguna, arrastra la columna de una tabla sobre la de la otra:

Desde (una fila)Hacia (muchas filas)
Proyectos [ID proyecto]Tareas [ID proyecto]
Proyectos [ID proyecto]Módulos [ID proyecto]
Ciclos [ID ciclo]Tareas [ID ciclo]
Tareas [ID tarea]Horas [ID tarea]
Tareas [ID tarea]Responsables [ID tarea]

Si Power BI crea relaciones por Código, Proyecto o Persona (texto), bórralas: deja solo las de la tabla. Las uniones por ID son las seguras, porque dos proyectos o dos personas pueden llamarse igual.

Medidas para empezar

En Power BI: Modelado → Nueva medida, y pega cada línea. Los tiempos vienen en minutos; estas medidas los pasan a horas.

Horas registradas = SUM ( Horas[Minutos] ) / 60
Horas estimadas = SUM ( Tareas[Minutos estimados] ) / 60
Desviación % = DIVIDE ( SUM ( Tareas[Minutos registrados] ) - SUM ( Tareas[Minutos estimados] ), SUM ( Tareas[Minutos estimados] ) )
Ocupación % = DIVIDE ( SUM ( Carga[Planificado (min)] ), SUM ( Carga[Capacidad (min)] ) )
Tareas abiertas = CALCULATE ( COUNTROWS ( Tareas ), NOT Tareas[Tipo de estado] IN { "Hecha", "Cancelada" } )

Ideas de gráficos: horas por persona y semana (Horas[Día] en el eje, Personas[Persona] como leyenda); estimado frente a registrado por proyecto; ocupación por persona con Carga (más de 100 % es sobrecarga); tareas abiertas por tipo de estado y prioridad.

5. Publicar en Power BI Service

  1. Publica el informe desde Power BI Desktop (Inicio → Publicar).
  2. En Power BI Service, abre el modelo semántico → Configuración → Credenciales del origen de datos → Editar credenciales: autenticación Anónima, nivel de privacidad Organizativo y marca Omitir conexión de prueba.
  3. En Actualización programada, actívala y elige cada cuánto (por ejemplo, cada mañana).

No hace falta puerta de enlace (gateway): Plane está en Internet. El token queda guardado dentro del fichero .pbix; comparte el informe publicado, no el fichero.

6. Si algo falla

401El token está mal copiado, caducó o se borró. Crea otro y cámbialo en Archivo → Opciones y configuración → Configuración de origen de datos.
404 «Espacio no encontrado»El nombre del espacio de la dirección está mal, o el dueño del token no es miembro de ese espacio.
404 «No existe la tabla»El final de la dirección está mal escrito. Las tablas son: proyectos, tareas, horas, responsables, personas, ciclos, modulos y carga (sin tildes).
400Una fecha de desde o hasta no tiene el formato AAAA-MM-DD, o en carga el periodo pasa de tres meses.
429Demasiadas peticiones en un minuto. Espera un minuto y vuelve a actualizar; si pasa a menudo, pide al administrador que suba el límite (API_KEY_RATE_LIMIT).
Faltan horas de otras personasEl token no es de un administrador del espacio: solo trae las tuyas.
No aparece un proyectoEl dueño del token no es miembro de ese proyecto, o el proyecto está archivado.
